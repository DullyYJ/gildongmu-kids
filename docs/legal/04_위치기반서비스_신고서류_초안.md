## 1.2 서비스 내용

1. **가족구성원 위치 보기**: 보호자가 연결한 가족구성원의 현재 위치와 지난 길(최근 7일 · 최대 10개)을 지도에 표시
2. **안전 알림**: 보호자가 등록한 장소에 도착 · 출발 · 도착하지 않음, 평소 가지 않던 곳(낯선 곳), 위치 공유 꺼짐, 오래 위치가 오지 않음, 가족구성원 폰 배터리 부족, 날씨 알림
3. **긴급 호출 · 데리러 와줘**: 가족구성원이 버튼을 누르면 연결된 보호자에게 즉시 알림(누른 시각과 그 위치, 가까운 장소 이름)
4. **가족 소통**: 보호자와 가족구성원의 짧은 대화 · 미션 · 응원 문구
5. 이용자 표시: 보호자가 가족구성원 위치를 보는 동안 가족구성원 앱 맨 위 줄과 알림에 "부모님이 지금 내 위치를 보고 있어요"를 보여 **가족구성원이 항상 알 수 있게** 함

## 1.3 이용자와 이용 조건

- **이용자**: 보호자(법정대리인) + 가족구성원(만 13세 이상). **만 12세 이하는 제공하지 않음**(위치정보법 제26조의 서류 제출 절차를 두지 않기 위해 이용 연령에서 제외).
- **동의**: 가족구성원 앱 첫 실행 때 보호자 동의 + 가족구성원 본인 동의를 **둘 다** 받아야 위치 공유가 시작됨. 문구는 쉬운 말로, 보내는 주기 · 보여 주는 사람 · 보관 기간 · 철회 방법 포함. 동의 문구가 바뀌면 모든 가족구성원 기기가 다시 동의해야 함(동의 버전 관리).
- **법정대리인 확인**: 보호자 앱에서 가족구성원 위치를 보기 전에 "법정대리인 · 가족구성원 만 13세 이상 · 가족구성원에게 알림 · 몰래 확인 안 함 · 거짓이면 책임" 항목을 확인하게 하고, 확인 시각과 버전을 기록. 확인 전에는 위치 · 알림이 보호자에게 제공되지 않음.
- **철회**: 가족구성원 앱 설정에서 언제든 위치 공유 끄기 · 동의 철회. 연결 해제 시 해당 가족구성원의 위치 · 경로 · 장소 · 대화 자료는 즉시 삭제.

## 1.4 요금 · 수익 모델

- 가족구성원 앱 무료 · 긴급 호출 알림 무료.

## 2.2 개인위치정보 흐름

| 단계 | 내용 |
|---|---|
| 1 수집 | 가족구성원 앱이 기기 위치 센서로 측정. 동의(보호자 + 가족구성원)가 있고 연결된 보호자가 있을 때만 서버로 전송 |
| 2 전송 | HTTPS. 평소 약 3~8분 간격, 보호자가 지도를 보는 동안 2.5~15초, 긴급 호출 뒤 30분은 빠르게 |
| 3 저장 | 가족구성원당 **현재 위치 1건**을 덮어쓰기. 지난 위치 점은 3일, 지난 길 7일(10개), 머문 곳 30일(200개), 긴급 호출 7일 |
| 4 제공 | 연결된 보호자 앱이 서버에 요청하면, 법정대리인 확인이 된 보호자에게만. 제공할 때마다 가족구성원 앱에 "보고 있어요" 표시 |
| 5 기록 | 제공 시마다 시각 · 가족구성원 기기 번호 · 보호자 기기 번호 · 종류만 기록(**좌표 없음**), 약 200일 보관 |
| 6 파기 | 기간이 지나면 서버가 10분마다 삭제. 연결 해제 시 즉시 삭제(이용 · 제공 사실 기록은 법정 기간 보관) |

## 2.3 위치정보를 처리하는 설비

| 설비 | 역할 | 위치정보 저장 |
|---|---|---|
| Cloudflare Workers | 요청 처리 · 판단 | 저장하지 않음(처리만) |
| Cloudflare D1 | 데이터베이스 | 위 2.2의 3 항목 저장 |
| Cloudflare Durable Object(허브, 선택 기능) | 실시간 깨우기 신호 전달 | **위치 · 개인정보 저장 안 함** |
| Google FCM | 푸시 전송 | 위치 좌표를 싣지 않음(알림 문구 · 종류만) |
| 기기 | 측정 · 표시 | 마지막 화면 일부를 기기 안에 임시 보관 |

[Cloudflare 데이터 보관 국가 · 지역 설정과 계약 형태(처리위탁 · 국외 이전)를 신고 전에 확인해 기재]

## 3.2 기술적 보호조치

| 항목 | 내용 | 확인 방법 |
|---|---|---|
| 통신 암호화 | 기기 ↔ 서버 전 구간 HTTPS | 서버 주소가 https 만 사용 |
| 인증 | 기기마다 임의의 번호와 비밀키(서비스가 만든 값). 서버에는 비밀키의 **해시만** 저장하고 요청마다 확인 | 시험 · 코드 |
| 접근 통제 | 연결된 보호자만 해당 가족구성원 정보 조회. 연결되지 않은 기기는 403 | 시험(guardian · watch) |
| 법정대리인 확인 | 확인 전에는 위치 · 위치 관련 동작 · "보는 중" 표시를 모두 막음 | 시험(guardian 23) |
| 최소 수집 | 이름 · 전화번호 · 이메일 · 사진 · 광고 식별자 수집 안 함. 위치는 가족구성원당 현재 1건(덮어쓰기) | 처리방침 2항 |
| 이용·제공 사실 자동 기록 | 시각 · 가족구성원 · 보호자 · 종류, **좌표 제외**, 약 200일 보관 | `lbs` 표 · 시험 |
| 자동 삭제 | 보유 기간이 지난 자료를 10분마다 삭제, 연결 해제 시 즉시 삭제 | 시험(route_keep · watch) |
| 공유 시 표시 | 보호자가 볼 때마다 가족구성원 앱에 표시 | 시험 |
| 입력 검증 | 좌표 범위 · 순간이동 · 부정확 위치 걸러냄, 문자 길이 제한 | 시험(locjump) |
| 푸시 | 알림에 좌표를 싣지 않음. 죽은 토큰 자동 삭제 | 코드 |
| 결제 | 구독 확인은 서버가 구글에 직접 확인. 앱이 보낸 '샀다'는 말을 믿지 않음 | 시험(billing) |

## 3.3 물리적 보호조치

자체 서버실을 운영하지 않고, 클라우드 사업자(Cloudflare)의 데이터센터 보안(출입 통제 · 설비 보호)에 위탁합니다. 운영자의 개발 기기는 화면 잠금 · 디스크 암호화를 적용합니다 [적용 확인].
